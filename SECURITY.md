# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it privately:

- through GitHub's private vulnerability reporting
  (https://github.com/s3onghyun/nvim-edu/security/advisories/new, or *Security* tab ›
  *Report a vulnerability*) when the repository shows it, or
- by email to s3onghyun.hong@gmail.com.

Include a clear description, affected files or URLs, reproduction steps or a minimal
proof of concept, impact, and any suggested mitigation. Please do not include secrets
or personal data. We will acknowledge the report, investigate privately, and agree on
disclosure timing with you when possible. This is a one-person project, so replies are
best effort.

## Scope

This policy covers the code and GitHub Actions in this repository and the deployed
GitHub Pages site (https://s3onghyun.github.io/nvim-edu/). How CI keeps pull requests away from the
deployment is described in [docs/MAINTAINERS.md](docs/MAINTAINERS.md). It does not promise support for third-party dependencies or forks,
but reports involving them are welcome when they affect this project.
