# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting for this repository:
https://github.com/s3onghyun/nvim-edu/security/advisories/new

Include a clear description, affected files or URLs, reproduction steps or a minimal
proof of concept, impact, and any suggested mitigation. Please do not include secrets
or personal data. We will acknowledge the report, investigate privately, and agree on
disclosure timing with you when possible.

## Scope

This policy covers the code and GitHub Actions in this repository and the deployed
GitHub Pages site. It does not promise support for third-party dependencies or forks,
but reports involving them are welcome when they affect this project.
